## Brand & Style

This design system expresses the visual identity of a high-rigor Java Backend Developer. It bridges the modern developer aesthetics seen in Linear, Vercel, and GitHub with the architectural precision expected of an enterprise backend engineer. 

The aesthetic is built on:
- **Disciplined Dark Mode & Bento Grid Layout:** High-density, modular information packaging that allows recruiters to parse technical stack competency, academic foundation, and project capabilities within seconds.
- **Architectural Credibility:** Restrained use of color, high typographic contrast, and technical monospaced details that highlight data flow, system boundaries, and backend architecture over decorative animations.
- **Precision Glass & Surface Elevation:** Micro-borders with low-opacity highlights, ambient violet-blue backdrops, and strictly structured surfaces (`#111722` and `#151C29`) resting on deep space neutrals (`#080A0F`).

## Colors

The palette is engineered specifically for dark interfaces, delivering WCAG AAA contrast for technical text while maintaining a calm, focused environment.

- **Primary Background (`#080A0F`) & Secondary Background (`#0D1117`):** Foundation tones providing deep atmospheric contrast without pure-black harshness.
- **Card Surfaces (`#111722`, `#151C29`):** Slate-tinted blue-black surfaces that anchor content blocks into defined, scannable structures.
- **Primary Accent (`#6C8CFF`) & Secondary Accent (`#8B5CF6`):** Dual indigo-violet accents used for focal actions, selected states, and progressive gradient highlights.
- **Success Accent (`#35D07F`):** Functional indicator reserved for real-time status cues (e.g., active availability for hiring) and system health checks.
- **Text Tiers (`#F4F7FB`, `#9BA7B7`, `#697586`):** Calibrated luminance scale ensuring primary text stays crisp, metadata remains scannable, and annotations stay non-intrusive.

## Typography

Typography balances structural clarity and developer credibility:
- **Headings (Plus Jakarta Sans):** Geometric and authoritative with tight tracking (`-0.02em` to `-0.03em`) to project confidence and modern polish.
- **Body & Content (Inter):** Highly legible neutral grotesque with generous line height for effortless parsing of technical narratives, role descriptions, and academic context.
- **Metadata, Eyebrows & Code (JetBrains Mono):** Monospaced technical treatment used for numbering (`01 / ABOUT ME`), terminal output lines, architecture breadcrumbs (`React → REST API → Spring Boot`), and tech-stack tokens.

## Layout & Spacing

The portfolio is structured around a responsive **Bento Grid** architecture within a centered max-width boundary of 1280px.

- **Desktop (≥ 1200px):** 12-column grid system with 24px gutters. Bento sections use asymmetrical spans: the hero introduction claims 8 columns while supporting telemetry cards occupy 4 columns. Main project cards divide into equal 6-column splits for content and preview areas.
- **Tablet (768px – 1199px):** 6-column or 2-column simplified grid with 16px gutters. Bento panels adapt to half-width or full-width blocks, prioritizing primary project highlights.
- **Mobile (< 768px):** Single-column vertical stream. Minimum horizontal gutters are 18px. Cards drop horizontal split orientations, stacking media previews above textual technical breakdowns.
- **Vertical Rhythm:** Sections maintain a 96px vertical cadence on desktop, compressed to 56px on mobile. Bento containers enforce strict internal padding tiers (32px for hero/projects, 24px for skills/education, 16px for compact metadata cards).

## Elevation & Depth

Depth is established via **layered surface luminescence and micro-borders**, rejecting heavy drop shadows that muddy dark themes:

- **Level 0 (Canvas):** Base viewport `#080A0F` paired with an optional radial gradient mask (`ellipse at top: rgba(108, 140, 255, 0.05)`).
- **Level 1 (Bento Panels):** Surface `#111722` encased in a hairline border `rgba(255, 255, 255, 0.08)`. Subtle interior rim light achieved using `box-shadow: inset 0 1px 0 0 rgba(255, 255, 255, 0.05)`.
- **Level 2 (Interactive / Hovered Cards):** On hover, panels subtly elevate (`translateY(-3px)`), the background transitions to `#151C29`, and the border shifts to `rgba(108, 140, 255, 0.50)` with an ambient violet-blue glow (`box-shadow: 0 12px 32px -8px rgba(108, 140, 255, 0.12)`).
- **Level 3 (Modals & Overlays):** Case study panels feature full glassmorphic backing (`rgba(17, 23, 34, 0.85)` with `backdrop-filter: blur(16px)`), framed with high-clarity subtle borders.

## Shapes

The design uses a refined, rounded visual rhythm:
- **Containers & Bento Cards:** Strict `16px` to `20px` corner radii (`rounded-xl` to `rounded-2xl`) creating cohesive modules.
- **Interactive Controls (Buttons & Inputs):** `8px` to `10px` roundedness, providing tactical click targets that stay sharp and purposeful.
- **Tech Stack & Status Chips:** `6px` to `9999px` (fully pill-shaped for status badges like availability indicators; subtly rounded `6px` rectangles for JetBrains Mono tech pills to conserve horizontal rhythm).

## Components

### Buttons
- **Primary Action (e.g., "View My Projects"):** Background gradient `linear-gradient(135deg, #6C8CFF 0%, #8B5CF6 100%)`, text `#FFFFFF`, font Inter 500. Box shadow `0 4px 16px rgba(108, 140, 255, 0.25)`. Hover raises scale subtly (1.02) and deepens glow.
- **Secondary / Ghost Action (e.g., "Download CV", "GitHub"):** Background `rgba(255, 255, 255, 0.04)`, border `1px solid rgba(255, 255, 255, 0.10)`, text `#F4F7FB`. Hover background `rgba(255, 255, 255, 0.08)` and border `#6C8CFF`.
- **Icon Buttons:** Fixed 40x40px or 36x36px squares, centered SVGs, accessible `aria-label`, border radius `8px`.

### Bento Cards
- Background `#111722`, border `1px solid rgba(255, 255, 255, 0.08)`, border radius `20px`, padding `24px` to `32px`. Transitions on border color and transform set to `200ms cubic-bezier(0.16, 1, 0.3, 1)`.

### Tech Stack Chips & Pills
- Container: Background `rgba(255, 255, 255, 0.04)`, border `1px solid rgba(255, 255, 255, 0.06)`, radius `6px`, padding `4px 10px`.
- Content: Font `JetBrains Mono`, 12px, text color `#9BA7B7`.

### Status Indicators
- Status badge: Flex container with 8px radius, border `rgba(53, 208, 127, 0.2)`. Leading 8px green pulse dot (`#35D07F` with ping animation), followed by text in JetBrains Mono 12px `#35D07F`.

### Terminal Accent Line
- Monospaced line set in `#697586` with command prompt highlight (`chinh@portfolio:~$`) in `#6C8CFF`, conveying command-line familiarity without overwhelming non-technical visitors.

### Case Study Expandable Modal
- Overlay: Background `rgba(8, 10, 15, 0.8)` with backdrop blur `12px`.
- Modal Frame: Surface `#111722`, border `1px solid rgba(255, 255, 255, 0.12)`, radius `20px`, max-width `720px`. Categorized structured headers (Overview, Contribution, Challenges, Learnings) with clear close button (`Esc` enabled).
